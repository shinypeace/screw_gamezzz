# Мастерская болтов

Вертикальная браузерная головоломка для телефонов и VK Mini Apps. Переносите болты в открытые отверстия: деревянные планки вращаются на последнем креплении и падают, когда освобождаются все крепления.

## Запуск

Node.js 22.12+:

```bash
npm ci
npm run dev
npm run build
npm test
npm run validate:levels
```

Vite использует относительные URL, поэтому игра работает в подпапке GitHub Pages и внутри VK WebView. `dev.html` — исходная HTML-точка входа; `npm run dev` обслуживает её по `/`. Команда `npm run build` собирает `dist` и обновляет готовый статический экспорт в корне: `index.html`, `assets/`, `.nojekyll` и `.pages-export.json`. После изменения исходников перед отправкой в GitHub нужно выполнить сборку и включить обновлённый экспорт в коммит.

GitHub Pages поддерживает оба способа публикации: **Deploy from a branch → main → / (root)** использует готовый экспорт в корне, **GitHub Actions** использует проверенный `dist` из `.github/workflows/pages.yml`. В опубликованной странице нет ссылок на `/src/main.ts`; браузер получает скомпилированные JavaScript, CSS и изображения. `npm run preview` открывает сборку `dist` для локальной проверки.

Каталог хранится в шести модулях `src/levels/` по 100 уровней. Сборка сохраняет их отдельными JS-файлами с относительными URL: основной код игры не содержит многомегабайтного массива. `scripts/write-level-catalog.ts` использует ту же упаковку при пересборке уровней.

## Содержание

- 600 воспроизводимых уровней из 42 базовых конструкций: среди них робот, краб, ракета, ключ, сова, поезд, корона и спутник. Первые 30 знакомят с разными рисунками; дальнейшие уровни меняют связи, слои перекрытия и свободные отверстия. Каталог собирается заранее, а решения и различия между конструкциями проверяются отдельно.
- Физика Matter.js: вращение вокруг оставшегося болта, инерция, качание и столкновения с другими болтами. Сквозные отверстия движутся вместе с деревом; совместив их с отверстиями доски, можно закрепить деталь снова.
- Карта уровней, звёзды, отдельные сохранения незавершённой кампании и вызова дня, жизни с восстановлением каждые 30 минут. «Продолжить» в главном меню возобновляет обычный уровень; ежедневная попытка доступна из вкладки заданий. Успешная попытка возвращает потраченную жизнь.
- Семидневная награда за вход, три ежедневных задания и ежедневная головоломка. Дата определяется по UTC+3.
- Четыре расходуемых буста, шесть оформлений болтов и пять фонов. Бусты доступны за игровую валюту или rewarded-видео; исчерпанная подсказка отмечается плашкой AD. Неоткрытые оформления скрыты. Ограничений магазина по уровню нет; цены рассчитаны на сбор коллекции примерно к уровню 300.
- Отдельные растровые кнопки, панели, иконки, поверхности и фоны. В интерфейсе нет SVG или emoji.
- На телефоне поле занимает всю ширину доступного экрана; на компьютере сохраняется вертикальная область. Короткие экраны с баннером используют компактные панели и страницы коллекции, карты и магазина.

## VK Mini Apps

Используется официальный `@vkontakte/vk-bridge`. При запуске из VK выполняются `VKWebAppInit` и `VKWebAppGetUserInfo`; локальный прогресс привязан к ID пользователя. Облачная копия сохраняется через `VKWebAppStorageGet/Set`, при ошибках остаётся локальный прогресс и включается повторная синхронизация. Звёзды и контрольные точки сжимаются. Если две движущиеся доски вместе превышают лимит значения хранилища VK, облако сохраняет в первую очередь кампанию, а ежедневная попытка остаётся в локальной копии на этом устройстве.

Для размещения создайте или откройте своё приложение в кабинете VK, укажите опубликованный HTTPS URL GitHub Pages как адрес приложения и включите нужные рекламные форматы в кабинете. App ID и секреты в клиентском коде не требуются: VK передаёт параметры запуска в URL. Доступность реальной рекламы зависит от настройки приложения и клиента VK.

- Banner: нижний баннер во всех вкладках и на игровом поле; `resize`, обработка overlay-высоты и safe area. Интерфейс располагается выше занятой рекламой области.
- Interstitial: естественный переход между уровнями, минимум три перехода и две минуты между показами.
- Reward: монеты, жизни, бусты и подсказка. Награда выдаётся только после ответа SDK `result: true`; закрытое, недоступное или неуспешное видео награды не даёт.
- При сворачивании VK/WebView и рекламе звук и игровой таймер приостанавливаются.

Обычный запуск GitHub Pages работает как гостевой режим с локальными сохранениями. VK-профиль, облако и настоящая реклама требуют запуска внутри VK. Клиентские покупки используют только игровую валюту, платежей реальными деньгами нет.

## Проверки и файлы

`npm run validate:levels` воспроизводит решения каталога и проверяет геометрию, минимальные расстояния на мобильном поле, поддержку планок, отмену, дополнительные отверстия и восстановление. Проверки уникальности сравнивают крепления и порядок перекрытия деталей. Модульные проверки охватывают экономику, ежедневные награды, рекламу, облачные контрольные точки, возвращение болтов, физические столкновения и восстановление движения.

`preview-materials/` и `.local/` исключены из Git. Маркетинговые материалы лежат только в папке на компьютере. Условия экономического баланса описаны в `docs/economy.md`.

`npm run build:levels` пересобирает каталог из исходного генератора и проверяет решаемость каждой конструкции. Это отдельный шаг разработки; обычная сборка использует уже проверенный каталог, и телефон не тратит время запуска на генерацию и решение всей кампании.

Подсказки на игровом поле учитывают текущее положение деталей, доступные отверстия и болты, на которых лежит свободная балка. Они подсвечивают допустимый перенос; игрок выполняет его сам. Если сейчас подходящего переноса нет, можно дождаться движения деталей, отменить ход или открыть дополнительное отверстие.

## Музыкальные файлы

Для самостоятельной загрузки через GitHub положите два MP3 непосредственно в папку `assets/audio/` репозитория: `menu.mp3` для главного меню, магазина и других вкладок, `game.mp3` для игрового поля. При публикации из ветки Pages они подключатся без изменения кода. `npm run build` также сохраняет эти файлы в статическом экспорте и переносит их в `dist`, поэтому сборка через Actions их не потеряет. Для локальной разработки можно хранить исходные треки в `public/assets/audio/`. Если трек есть в обеих папках, при публикации используется версия из `assets/audio/`.

Музыка зациклена и плавно переключается между меню и полем за 0,8 секунды. Она запускается после первого касания или нажатия клавиши, как требуют мобильные браузеры; настройки музыки и звуков независимы. При сворачивании приложения и рекламном видео воспроизведение приостанавливается. До добавления MP3 используется тихая процедурная мелодия; отсутствие музыки не блокирует игру.
