# Мастерская болтов

Вертикальная браузерная головоломка для телефонов и VK Mini Apps. Переносите болты в открытые отверстия: деревянные планки вращаются на последнем креплении и падают, когда освобождаются все крепления.

## Запуск

Node.js 22.12+:

```bash
npm ci
npm run dev
npm run build
npm test
npm run validate:levels
```

Vite использует относительные URL. Сборка `dist` работает в подпапке GitHub Pages. Workflow `.github/workflows/pages.yml` проверяет проект и публикует `main` через GitHub Actions.

## Содержание

- 600 воспроизводимых уровней, четыре семейства конструкций, возрастающая сложность; для каждого поля генератор находит и проверяет решение.
- Поворот планок вокруг крепления, Matter.js для падения деталей, частицы, процедурное аудио и виброотклик.
- Карта уровней, звёзды, сохранение незавершённой игры, жизни с восстановлением каждые 30 минут. Успешная попытка возвращает потраченную жизнь.
- Семидневная награда за вход, три ежедневных задания и ежедневная головоломка. Дата определяется по UTC+3.
- Четыре расходуемых буста, шесть оформлений болтов и пять фонов. Бусты доступны за игровую валюту или rewarded-видео; исчерпанная подсказка отмечается плашкой AD. Неоткрытые оформления скрыты. Последний подарок становится доступным после уровня 300.
- Отдельные растровые кнопки, панели, иконки, поверхности и фоны. В интерфейсе нет SVG или emoji.

## VK Mini Apps

Используется официальный `@vkontakte/vk-bridge`. При запуске из VK выполняются `VKWebAppInit` и `VKWebAppGetUserInfo`; локальный прогресс привязан к ID пользователя. Облачная копия сохраняется через `VKWebAppStorageGet/Set`, при ошибках остаётся локальный прогресс и включается повторная синхронизация. Сжатые звёзды и контрольная точка укладываются в лимит значения хранилища.

Для размещения создайте или откройте своё приложение в кабинете VK, укажите опубликованный HTTPS URL GitHub Pages как адрес приложения и включите нужные рекламные форматы в кабинете. App ID и секреты в клиентском коде не требуются: VK передаёт параметры запуска в URL. Доступность реальной рекламы зависит от настройки приложения и клиента VK.

- Banner: нижний баннер в меню; `resize`, обработка overlay-высоты и safe area. На поле баннер скрывается.
- Interstitial: естественный переход между уровнями, минимум три перехода и две минуты между показами.
- Reward: монеты, жизни, бусты и подсказка. Награда выдаётся только после ответа SDK `result: true`; закрытое, недоступное или неуспешное видео награды не даёт.
- При сворачивании VK/WebView и рекламе звук и игровой таймер приостанавливаются.

Обычный запуск GitHub Pages работает как гостевой режим с локальными сохранениями. VK-профиль, облако и настоящая реклама требуют запуска внутри VK. Клиентские покупки используют только игровую валюту, платежей реальными деньгами нет.

## Проверки и файлы

`npm run validate:levels` воспроизводит решения всей кампании и проверяет геометрию, минимальные расстояния на мобильном поле, поддержку планок, отмену, дополнительные отверстия и восстановление. Модульные проверки охватывают экономику, ежедневные награды, рекламу и сохранения.

`preview-materials/` и `.local/` исключены из Git. Маркетинговые материалы лежат только в папке на компьютере. Условия экономического баланса описаны в `docs/economy.md`.
